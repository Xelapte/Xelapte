## 🚀 Featured project

### 🎙️ [Verity — Live-Radio Fact-Checking Platform](https://github.com/Xelapte/MedIA-Hackaton)
Built at the MedIA hackathon. Verity listens to **37 live radio stations across 13 countries**, transcribes them in real time with Whisper, extracts news claims with an LLM pipeline (n8n), fact-checks each claim against live web search, and streams the results to a Next.js dashboard — with a weighted per-station credibility score, bilingual (EN/FR) output, an interactive world map, and audio playback synced to the exact fact-checked moment.

`TypeScript` `Next.js` `Python` `n8n` `Whisper` `LLM orchestration`
